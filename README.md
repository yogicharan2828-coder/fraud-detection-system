# Intelligent Online Payment Fraud Detection System

A machine learning-based web application that helps identify potentially fraudulent online payment transactions. The system analyzes transaction details and predicts whether a transaction is likely to be fraudulent or legitimate.

## 🚀 Live Demo
(https://fraud-detection-system-86ji.onrender.com/)

## 📌 Features

- Fraud detection prediction
- User-friendly web interface
- Real-time transaction analysis
- Responsive design
- Flask-powered backend
- Machine Learning prediction logic

## 🔍 How It Works

1. User enters transaction details.
2. Data is sent to the Flask backend.
3. The machine learning model processes the transaction.
4. The system predicts whether the transaction is:
   - Fraudulent
   - Legitimate
5. Result is displayed instantly on the screen.




## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yogicharan2828-coder/fraud-detection-system.git
```

Move into the project folder:

```bash
cd fraud-detection
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
